# MOSAICO CARTA — O Mercado

Jogo isolado. Teste sem cronômetro.

Na vez de cada personagem: **Suas pistas** em cima, os quatro botões embaixo.

- Arriscar
- Capturar
- Comprar
- Consignar no balaio

Ordem: você → Nara → Ivo. Três voltas cada. Doze moedas.

O cronômetro por vez existe na regra; neste teste está desligado.

Abra `index.html`.
