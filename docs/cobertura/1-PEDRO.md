# Levantamento por recorte — 1 Pedro

Em 12/09/2026, os cinco capítulos NAA foram consultados. Nenhuma pauta foi autorada, por insuficiência ou ausência de uma unidade dedutiva com quatro campos e 25 fatos distintos, não por exclusão automática do gênero.

| Recorte | Decisão final desta entrega |
| --- | --- |
| 1Pe 1–2 | Saudação, esperança, metáforas e instruções avaliadas; blocos distintos não foram unidos artificialmente. |
| 1Pe 3.1-18; 20-22 | Reavaliados independentemente; continuam sem baralho/unidade próprios. Referências ao AT não foram completadas externamente. |
| 1Pe 3.19 | Questão dos espíritos em prisão fica expressamente fora por decisão do usuário; isso não exclui o capítulo. |
| 1Pe 4.1-5; 7-19 | Reavaliados; exortações e sofrimento não foram convertidos em alternativas normativas falsas. |
| 1Pe 4.6 | Questão fica expressamente fora; não se adotou a interpretação de cristãos já falecidos. |
| 1Pe 5.13 | Por decisão do usuário, “aquela” é entendida como Igreja/comunidade cristã. Essa é interpretação aprovada, não significado lexical de “Babilônia”; nenhuma localização geográfica é afirmada. O bloco permanece insuficiente para pauta. |

1 Pedro está **analisado**, com as exclusões pontuais acima e sem ambiguidades pendentes atribuídas ao usuário.
